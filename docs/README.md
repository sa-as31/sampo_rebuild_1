# 文档目录说明

本目录用于收纳项目根目录中与代码运行入口无直接关系的说明、论文和提取材料，让根目录保留启动、配置和核心说明文件。

## 目录结构

- `project/`：工程运行、训练、前端、评估和阶段性修复说明。
- `thesis/`：毕业论文、任务书、开题报告、文献综述、答辩材料和论文配图。
- `extracted/`：通过 MinerU 等工具提取出的 HTML / Markdown 中间材料。
- `paper/`：论文补充材料和外部论文附件。

## 根目录保留文件

- `README.md`：项目主说明。
- `AGENTS.md`：代理协作约定。
- `MODIFICATIONS_CN.md`：代码修改记录。
- `解疑.md`：问题解答记录。
- `main.py` / `main_gpu.py` / `manage.py`：主要运行入口。
- `Dockerfile*` / `docker-compose*.yml` / `requirements.txt`：环境和部署配置。
