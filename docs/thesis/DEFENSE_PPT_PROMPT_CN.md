三、项目背景与研究主题

这是一个面向多无人机场景的协同调度与动态路径规划毕业设计项目，研究方向属于多智能体路径规划（MAPF / LMAPF）、无人机协同调度和多智能体强化学习交叉领域。

项目聚焦的问题不是单架无人机如何找一条最短路，而是在复杂动态环境中，多个无人机如何在共享地图中协同执行任务，并尽量减少路径冲突、局部拥堵和无效等待，提高整体吞吐量和运行效率。

四、核心研究思路

本项目采用“传统规划 + 强化学习”的两阶段协同思路，而不是纯搜索或纯端到端学习。

2. 决策精炼阶段：
结合多智能体强化学习模型，在局部观测条件下根据邻近智能体、子目标引导和环境状态对动作进行进一步优化，实现局部冲突规避和路径细化。

3. 系统实现阶段：
在算法原型之外，还实现了训练、推理、回放、任务管理和前端可视化展示链路，形成一个可训练、可推理、可演示、可交互的毕业设计系统原型。

- 路径规划：A*、LB-A*、重规划模块、C++ 扩展规划器
- 后端：Python 服务接口
- 前端：Vue 3 + Vite
- 可视化能力：任务中心、运营大屏、2D/3D 联合运行视图、任务回放
- 工程能力：支持 CPU 训练、GPU 训练入口、Docker 部署
