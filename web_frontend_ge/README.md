# web_frontend_ge

`web_frontend_ge` 是当前仓库中继续推进中的 Vue 3 + Vite 前端重构版本，用于把无人机协同调度系统整理成更适合展示与答辩演示的界面。

## 当前页面

- `/login`
  - 展示型登录入口，提供角色切换和演示账号预设
- `/dashboard`
  - 系统总览首页，强调任务焦点、动态流和舰队摘要
- `/tasks`
  - 任务看板与列表双视图
- `/tasks/:id`
  - 单任务详情工作台，包含主舞台、参数、告警和回放
- `/fleet`
  - 舰队覆盖、在线机组和维护队列观测页

## 设计方向

- 采用暖白、低饱和、编辑式的视觉语言
- 深色舞台只用于任务运行和舰队观测等高对比区域
- 强调“大容器、少卡片、清晰叙事”的毕业设计展示节奏

## 运行方式

```bash
npm install
npm run dev
```

构建验证：

```bash
npm run build
```
