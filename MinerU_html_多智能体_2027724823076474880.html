Abstract

Lifelong Multi-Agent Path Finding (LMAPF) focuses on planningconflict-free paths for agents, like autonomous vehicles, that arecontinuously assigned new tasks. The synergy of search-basedand learning-based methods holds promise for striking a balancein-between effectiveness and efficiency but still faces several chal-lenges such as inferior initial paths, weak search-learning synergyand low sample utilization rate. To address these issues, this paperproposes a new synergized LMAPF approach, named Synergis-tic Multi-Agent Path Optimization (SMAPO), which consists oftwo tightly-coupled phases: Primordial Planning and Decision Re-finement. In the Primordial Planning phase, we introduce a novelload-balanced 𝖠⋆\mathsf { A } ^ { \star } algorithm that integrates planned and perceivedcongestion costs, which enhances initial solution quality by evenlydistributing spatiotemporal traffic loads, thereby mitigating poten-tial conflicts. In the Decision Refinement phase, we propose a novelEncoder-Decoder based neural network to learn a collaborativeoptimization policy through multi-agent reinforcement learning.In addition, we leverage dual transformations to augment trajec-tory samples during online learning, enhancing both the sampleutilization rate and overall learning stability. Extensive experimentsreveal that our SMAPO is superior to the state-of-the-art baselinesin effectiveness, efficiency, and generalization capability. Sourcecode is available at https://github.com/ByteUser-blues/SMAPO.

1 Introduction

Multi-agent path finding (MAPF) aims to find a set of cost-effectiveand conflict-free paths for autonomous vehicles, navigating themto reach their goal positions [37]. Lifelong MAPF (LMAPF) consid-ers more practical challenges by continually planning the agents’paths to new goal positions throughout their lifetime [19]. LMAPFhas extensive application scenarios, including warehouse logis-tics [24], traffic management [14], automated valet parking [28]and airport operations [27]. The challenge of LMAPF over MAPF isnot only resolving immediate conflicts but also ensuring lifelongefficiency (e.g., throughput). The prevalent MAPF baseline methodis search-based, represented by conflict-based search (CBS) [32],which individually plans each agent’s path and exhaustively re-solves conflicts of the path set with the lowest cost. SubsequentMAPF works employ suboptimal CBS-like methods by relaxingcost bounds [18, 39] or prioritizing primary conflicts [23, 39] tomore quickly search for feasible and cost-effective paths. To extendsearch-based methods to LMAPF, current work decomposes LMAPFinto a series of MAPF instances with paths for all agents replannedat each time step [9] or within a time window [19, 38]. However, asscenario complexity increases (e.g., higher agent and obstacle den-sity), planning times grow significantly, and overall performancedeteriorates. This challenge becomes more severe in LMAPF, wherefrequent replanning further increases computational overhead.

Recently, learning-based methods have emerged as a novel andeffective paradigm for both optimization [3, 10, 25] and planning [4,8, 15]. In planning task, neural networks are utilized to learn theplanning priority order of agents [42] or generate feasible paths inan end-to-end manner [30]. Thus, it allows direct extension fromMAPF to LMAPF while avoiding the extensive online computa-tion required by search-based methods. By facilitating effective

multi-agent reinforcement learning (MARL) and imitation learn-ing (IL), learning-based methods train agents to search feasiblepaths through efficient collaboration [1, 7, 22, 26, 40]. These meth-ods promise scalable and efficient decision making. However, theyencounter challenges, like the data-driven learning fashion poseschallenges in sample utilization rate and overall learning effective-ness, often resulting in poor generalization to unseen maps, whichare less generic and lower throughput than search-based methods.

To combine the respective strengths of search and learning meth-ods, recent approaches have explored the integration of search-based and learning-based methods. MATS-LP algorithm [35] incor-porates Monte Carlo tree search to enhance the policy network.Switcher method [36] investigates an adaptive switching strat-egy between search and learning methods. Furthermore, Followermethod [34] adopts a more integrated approach by integratingheuristic search for path planning and reinforcement learning forconflict resolution. Despite their potential, these hybrid approachesface critical limitations: their search components either generatemyopic initial paths (Follower, Switcher) or demand excessive com-putation (MATS-LP), while weak search-learning synergy under-mines both sample efficiency and generalization.

To address these challenges, we introduce SMAPO (SynergisticMulti-Agent Path Optimization), a novel search-integrated learning-based approach that enables rapid generation and optimization ofload-balanced path sets across diverse scenarios using a singleunified model. SMAPO introduces three key contributions:

  1. SMAPO integrates search and learning in a tightly coupled,two-phase framework. In the Primordial Planning phase, a specifi-cally designed 𝖠⋆\mathsf { A } ^ { \star } algorithm generates initial paths, which are thenrefined using MARL in the Decision Refinement phase. The MARL-based planning results feed real-time adjustments to the congestioncosts back into the 𝖠⋆\mathsf { A } ^ { \star } planning. This feedback loop dynamicallyadapts to environment changes, improving both short-term andlong-term path optimization.

  2. In the Primordial Planning phase, we introduce a novel load-balanced 𝔸*\mathbb { A } ^ { \ast } algorithm that integrates both planned and perceivedcongestion costs into the agents’ spatio-temporal paths. This search-based approach reduces conflicts while maintaining efficiency byproactively balancing traffic loads across agents. The algorithmenhances the quality of the initial path set, which serves as thefoundation for the subsequent learning phase.

  3. In the Decision Refinement phase, we propose an Encoder-Decoder-based architecture to learn a collaborative optimizationpolicy through multi-agent reinforcement learning. To stabilizeMARL training, we propose a sample-efficient Dual Transformationstrategy that augments trajectories with dual variants, enhancinggeneralization and convergence.

In summary, SMAPO enhances the synergy between search andlearning mechanisms, significantly improving generalization capa-bilities across diverse scenarios while maintaining computationalefficiency in generating conflict-free and cost-effective path set.Experimental results demonstrate that SMAPO significantly out-performs existing learning-based methods while achieving a su-perior throughput-efficiency balance compared to search-basedapproaches. Further ablation studies demonstrate core designs ofSMAPO collaboratively contribute to superior performance.

2 Related Works

2.1 Multi-Agent Path Finding

Methods for solving MAPF problem can be divided into two cat-egories: search-based methods and learning-based methods. Theessence of search-based methods for solving MAPF problems isthe use of search techniques to conduct centralized path planningand conflict resolution, with the most notable being CBS [32], acomplete and optimal two-level solver. The core of CBS lies in start-ing from a set of shortest but infeasible paths and exhaustivelyresolving the existing conflicts. Subsequently, CBS variants, suchas CBICS [39] and EECBS [18], accelerate the CBS algorithm withheuristic search for conflict selection and resolution. Another vari-ant, PBS [23], combines the ideas of Cooperative 𝖠⋆\mathsf { A } ^ { \star } (CA*) [33],where the high-level planning is similar to CBS, but the conflict res-olution involves assigning higher priority to one of the conflictingagents instead of adding additional constraints.

Compared to search-based methods, learning-based methodsleverage neural network parallelism to enhance algorithmic effi-ciency, enabling stable scalability to scenarios with larger agentcounts. This has led to a wealth of influential work, such as PRI-MAL [30], combined IL and reinforcement learning to solve theMAPF problem. Several studies have primarily focused on achiev-ing global information exchange among agents through communi-cation, thereby improving the quality of the solutions, includingMAGAT [21], DHC [26], and SCRIMP [40]. The latest work MAPF-GPT [1] utilizes the powerful fitting capability of DiffuserLites toreplicate expert behaviors, showcasing its potential in capturingand generalizing complex decision-making patterns.

2.2 Lifelong Multi-Agent Path-Finding

In LMAPF, the long-term nature of continuous goal allocation im-poses greater demands on the algorithm’s real-time performanceand adaptability, making search-based MAPF methods difficult toapply directly. An intuitive approach is to decompose LMAPF intoa series of MAPF instances, replanning paths for all agents at eachtime step [9], which leads to considerable planning time. The state-of-the-art method for leveraging the advanced centralized MAPFsolvers to address LMAPF tasks is RHCR [19], which utilizes cost-bounded MAPF solvers to solve LMAPF problems, balancing thepath cost minimization and conflict resolution efficiency. Comparedto the existing works, our study proactively balances traffic loadsacross agents, improving scalability to higher agent and obstacledensities while enhancing overall efficiency.

Unlike search-based MAPF methods, learning-based MAPF ap-proaches utilize neural networks for single-step decision-making,enabling direct extension to LMAPF problems. Notable examplesinclude the extended version of PRIMAL, PRIMAL2 [7], whichenhances agent collaboration and environmental understandingthrough detailed feature map design, as well as advanced learning-based MAPF methods like SCRIMP, MAPF-GPT, all of which canbe directly applied to LMAPF. Recently, several algorithms haveintegrated search-based strategies to enhance learning-based meth-ods. For instance, MATS-LP [35] improves the learned policy byincorporating Monte Carlo Tree Search (MCTS) while Follower [34]synergizes 𝔸⋆\mathbb { A } ^ { \star } with learning-based techniques to enhance both train-ing efficiency and effectiveness. The synergy of search-based and

learning-based methods holds promise for balancing effectivenessand efficiency. However, the loosely coupled frameworks of existingmethods still lead to issues such as myopic path generation andsubstantial computation overhead. To address these issues, SMAPOintroduces several novel design innovations that enhance search-learning synergy, enabling more cost-efficient path optimization.

6 Conclusion

In this paper, we propose SMAPO, a search-integrated learningframework for rapid generation and optimization of load-balancedpath sets. SMAPO comprises two tightly-coupled phases: 1) Pri-mordial Planning phase employing a novel load-balancing 𝔸⋆\mathbb { A } ^ { \star } algo-rithm that integrates planning and perceived congestion costs toenhance solution quality through spatiotemporal load distributionand conflict mitigation; 2) Decision Refinement phase formulatecollaborative path set optimization as the primary objective andemploy multi-agent reinforcement learning to develop an Encoder-Decoder-based cooperative policy. Additionally, we utilize dualtransformations to augment trajectory samples during online learn-ing, boosting sample utilization and overall learning stability. Ex-tensive evaluations on LMAPF benchmarks demonstrate SMAPO’sconsistent superiority over state-of-the-art learning methods and itssuperior performance-efficiency balance compared to search-basedapproaches. Future work involves enriching agent action diversityand extending SMAPO to dynamic obstacle environments.
