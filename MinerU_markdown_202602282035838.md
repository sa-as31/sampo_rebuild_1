# Abstract

Lifelong Multi-Agent Path Finding (LMAPF) focuses on planningconflict-free paths for agents, like autonomous vehicles, that arecontinuously assigned new tasks. The synergy of search-basedand learning-based methods holds promise for striking a balancein-between effectiveness and efficiency but still faces several chal-lenges such as inferior initial paths, weak search-learning synergyand low sample utilization rate. To address these issues, this paperproposes a new synergized LMAPF approach, named Synergis-tic Multi-Agent Path Optimization (SMAPO), which consists oftwo tightly-coupled phases: Primordial Planning and Decision Re-finement. In the Primordial Planning phase, we introduce a novelload-balanced $\mathsf { A } ^ { \star }$ algorithm that integrates planned and perceivedcongestion costs, which enhances initial solution quality by evenlydistributing spatiotemporal traffic loads, thereby mitigating poten-tial conflicts. In the Decision Refinement phase, we propose a novelEncoder-Decoder based neural network to learn a collaborativeoptimization policy through multi-agent reinforcement learning.In addition, we leverage dual transformations to augment trajec-tory samples during online learning, enhancing both the sampleutilization rate and overall learning stability. Extensive experimentsreveal that our SMAPO is superior to the state-of-the-art baselinesin effectiveness, efficiency, and generalization capability. Sourcecode is available at https://github.com/ByteUser-blues/SMAPO.

# 1 Introduction

Multi-agent path finding (MAPF) aims to find a set of cost-effectiveand conflict-free paths for autonomous vehicles, navigating themto reach their goal positions [37]. Lifelong MAPF (LMAPF) consid-ers more practical challenges by continually planning the agents’paths to new goal positions throughout their lifetime [19]. LMAPFhas extensive application scenarios, including warehouse logis-tics [24], traffic management [14], automated valet parking [28]and airport operations [27]. The challenge of LMAPF over MAPF isnot only resolving immediate conflicts but also ensuring lifelongefficiency (e.g., throughput). The prevalent MAPF baseline methodis search-based, represented by conflict-based search (CBS) [32],which individually plans each agent’s path and exhaustively re-solves conflicts of the path set with the lowest cost. SubsequentMAPF works employ suboptimal CBS-like methods by relaxingcost bounds [18, 39] or prioritizing primary conflicts [23, 39] tomore quickly search for feasible and cost-effective paths. To extendsearch-based methods to LMAPF, current work decomposes LMAPFinto a series of MAPF instances with paths for all agents replannedat each time step [9] or within a time window [19, 38]. However, asscenario complexity increases (e.g., higher agent and obstacle den-sity), planning times grow significantly, and overall performancedeteriorates. This challenge becomes more severe in LMAPF, wherefrequent replanning further increases computational overhead.

Recently, learning-based methods have emerged as a novel andeffective paradigm for both optimization [3, 10, 25] and planning [4,8, 15]. In planning task, neural networks are utilized to learn theplanning priority order of agents [42] or generate feasible paths inan end-to-end manner [30]. Thus, it allows direct extension fromMAPF to LMAPF while avoiding the extensive online computa-tion required by search-based methods. By facilitating effective

multi-agent reinforcement learning (MARL) and imitation learn-ing (IL), learning-based methods train agents to search feasiblepaths through efficient collaboration [1, 7, 22, 26, 40]. These meth-ods promise scalable and efficient decision making. However, theyencounter challenges, like the data-driven learning fashion poseschallenges in sample utilization rate and overall learning effective-ness, often resulting in poor generalization to unseen maps, whichare less generic and lower throughput than search-based methods.

To combine the respective strengths of search and learning meth-ods, recent approaches have explored the integration of search-based and learning-based methods. MATS-LP algorithm [35] incor-porates Monte Carlo tree search to enhance the policy network.Switcher method [36] investigates an adaptive switching strat-egy between search and learning methods. Furthermore, Followermethod [34] adopts a more integrated approach by integratingheuristic search for path planning and reinforcement learning forconflict resolution. Despite their potential, these hybrid approachesface critical limitations: their search components either generatemyopic initial paths (Follower, Switcher) or demand excessive com-putation (MATS-LP), while weak search-learning synergy under-mines both sample efficiency and generalization.

To address these challenges, we introduce SMAPO (SynergisticMulti-Agent Path Optimization), a novel search-integrated learning-based approach that enables rapid generation and optimization ofload-balanced path sets across diverse scenarios using a singleunified model. SMAPO introduces three key contributions:

1) SMAPO integrates search and learning in a tightly coupled,two-phase framework. In the Primordial Planning phase, a specifi-cally designed $\mathsf { A } ^ { \star }$ algorithm generates initial paths, which are thenrefined using MARL in the Decision Refinement phase. The MARL-based planning results feed real-time adjustments to the congestioncosts back into the $\mathsf { A } ^ { \star }$ planning. This feedback loop dynamicallyadapts to environment changes, improving both short-term andlong-term path optimization.

2) In the Primordial Planning phase, we introduce a novel load-balanced $\mathbb { A } ^ { \ast }$ algorithm that integrates both planned and perceivedcongestion costs into the agents’ spatio-temporal paths. This search-based approach reduces conflicts while maintaining efficiency byproactively balancing traffic loads across agents. The algorithmenhances the quality of the initial path set, which serves as thefoundation for the subsequent learning phase.

3) In the Decision Refinement phase, we propose an Encoder-Decoder-based architecture to learn a collaborative optimizationpolicy through multi-agent reinforcement learning. To stabilizeMARL training, we propose a sample-efficient Dual Transformationstrategy that augments trajectories with dual variants, enhancinggeneralization and convergence.

In summary, SMAPO enhances the synergy between search andlearning mechanisms, significantly improving generalization capa-bilities across diverse scenarios while maintaining computationalefficiency in generating conflict-free and cost-effective path set.Experimental results demonstrate that SMAPO significantly out-performs existing learning-based methods while achieving a su-perior throughput-efficiency balance compared to search-basedapproaches. Further ablation studies demonstrate core designs ofSMAPO collaboratively contribute to superior performance.

# 2 Related Works

# 2.1 Multi-Agent Path Finding

Methods for solving MAPF problem can be divided into two cat-egories: search-based methods and learning-based methods. Theessence of search-based methods for solving MAPF problems isthe use of search techniques to conduct centralized path planningand conflict resolution, with the most notable being CBS [32], acomplete and optimal two-level solver. The core of CBS lies in start-ing from a set of shortest but infeasible paths and exhaustivelyresolving the existing conflicts. Subsequently, CBS variants, suchas CBICS [39] and EECBS [18], accelerate the CBS algorithm withheuristic search for conflict selection and resolution. Another vari-ant, PBS [23], combines the ideas of Cooperative $\mathsf { A } ^ { \star }$ (CA*) [33],where the high-level planning is similar to CBS, but the conflict res-olution involves assigning higher priority to one of the conflictingagents instead of adding additional constraints.

Compared to search-based methods, learning-based methodsleverage neural network parallelism to enhance algorithmic effi-ciency, enabling stable scalability to scenarios with larger agentcounts. This has led to a wealth of influential work, such as PRI-MAL [30], combined IL and reinforcement learning to solve theMAPF problem. Several studies have primarily focused on achiev-ing global information exchange among agents through communi-cation, thereby improving the quality of the solutions, includingMAGAT [21], DHC [26], and SCRIMP [40]. The latest work MAPF-GPT [1] utilizes the powerful fitting capability of DiffuserLites toreplicate expert behaviors, showcasing its potential in capturingand generalizing complex decision-making patterns.

# 2.2 Lifelong Multi-Agent Path-Finding

In LMAPF, the long-term nature of continuous goal allocation im-poses greater demands on the algorithm’s real-time performanceand adaptability, making search-based MAPF methods difficult toapply directly. An intuitive approach is to decompose LMAPF intoa series of MAPF instances, replanning paths for all agents at eachtime step [9], which leads to considerable planning time. The state-of-the-art method for leveraging the advanced centralized MAPFsolvers to address LMAPF tasks is RHCR [19], which utilizes cost-bounded MAPF solvers to solve LMAPF problems, balancing thepath cost minimization and conflict resolution efficiency. Comparedto the existing works, our study proactively balances traffic loadsacross agents, improving scalability to higher agent and obstacledensities while enhancing overall efficiency.

Unlike search-based MAPF methods, learning-based MAPF ap-proaches utilize neural networks for single-step decision-making,enabling direct extension to LMAPF problems. Notable examplesinclude the extended version of PRIMAL, PRIMAL2 [7], whichenhances agent collaboration and environmental understandingthrough detailed feature map design, as well as advanced learning-based MAPF methods like SCRIMP, MAPF-GPT, all of which canbe directly applied to LMAPF. Recently, several algorithms haveintegrated search-based strategies to enhance learning-based meth-ods. For instance, MATS-LP [35] improves the learned policy byincorporating Monte Carlo Tree Search (MCTS) while Follower [34]synergizes $\mathbb { A } ^ { \star }$ with learning-based techniques to enhance both train-ing efficiency and effectiveness. The synergy of search-based and

learning-based methods holds promise for balancing effectivenessand efficiency. However, the loosely coupled frameworks of existingmethods still lead to issues such as myopic path generation andsubstantial computation overhead. To address these issues, SMAPOintroduces several novel design innovations that enhance search-learning synergy, enabling more cost-efficient path optimization.

# 4 Methodology

As shown in Figure 1, our synergistic multi-agent path optimizationalgorithm, named SMAPO, consists of two phases. The PrimordialPlanning phase utilizes Load-Balanced $\mathsf { A } ^ { \star }$ to quickly generate aninitial paths $\mathbb { S }$ that balance the map’s traffic load. The DecisionRefinement phase then further refine the planing results to avoidpotential conflicts. These two phases would engage the overall

planning process in turn to provide cost-efficient and conflict-freepaths online. We elaborate this collaboration paradigm next.

# 4.1 Primordial Planning (PP) Phase

The purpose of Primordial Planning phase is to obtain an initial setof paths through fast-search algorithm. To achieve this, we proposethe Load-Balanced $\mathbb { A } ^ { \ast }$ (LB-A*) algorithm, illustrated in the purplesection of Figure 1, which quickly generates initial paths of agentsthat balance the traffic load on the map. During the execution of LB-$\mathsf { A } ^ { \star }$ , the individual cost of a cell $c$ at time step ?? (when transitioninginto it) consists of two components: the Planned Congestion Cost(PlCC) and the Perceived Congestion Cost (PeCC):

$$
\operatorname {c o s t} (c, t) = \operatorname {c o s t} _ {P l C C} (c, t) + \operatorname {c o s t} _ {P e C C} (c, t). \tag {1}
$$

Once we obtain the costs, we could employ an analog of traditional$\mathsf { A } ^ { \star }$ algorithm to sequentially plan paths for agents in LMAPF.

4.1.1 Planned Congestion Cost. Motivation arises when generat-ing paths with ${ \mathrm { A } } ^ { * } { \mathrm { . } }$ , where conflict occurrences follow the principlethat: if one agent traverses a cell at time $t _ { 1 }$ and another agenttraverses the same cell at time $t _ { 2 }$ , the likelihood of a conflict oc-currence decreases as $| t _ { 2 } - t _ { 1 } |$ increases. This observation leads tothe development of PlCC, a novel mechanism designed to partitionthe temporal domain into multiple segments while meticulouslyaccounting for the trajectories of moving agents. Concretely, toestimate the PlCC of the cell $( x , y )$ at time ?? , we first, for the previ-ously planned trajectories, count the number of agents located inthe grid cell $( x , y )$ at the time step $t + k$ , and denote the count as$n u m _ { k } = C o u n t ( x , y , t + k )$ , where $k \in [ - \Delta t , \Delta t ]$ and the function?????????? counts the number of occurrences of a given triple in theset Planned Paths. The cost of time $t _ { 0 } + k$ for the grid cell $( x _ { 0 } , y _ { 0 } )$ iscalculated as:

$$
f \left(\operatorname {n u m} _ {k}\right) = \left\{ \begin{array}{c} \alpha * \operatorname {n u m} _ {k} ^ {2}, k = 0, \\ \beta * \operatorname {n u m} _ {k} * \lambda^ {| k |}, k \neq 0, \end{array} \right. \tag {2}
$$

where $\lambda \in ( 0 , 1 ]$ controls the decay of the cost impact as functionof the temporal distance. $\alpha$ and $\beta$ are parameters employed tomodulate the cost base when agents occupy the grid cell at thesame time $\left( k = 0 \right)$ ) and different times $( k \neq 0 )$ . In the training andtesting conducted in paper, we set $\alpha = 2$ , $\beta = 0 . 5$ , $\lambda = 0 . 8$ .

The PlCC for the grid cell $( x , y )$ at time $t$ is the sum of the costcontributions from all time points within the interval $\left[ t - \Delta t , t + \Delta t \right]$given by:

$$
\operatorname {c o s t} _ {P l C C} (x, y, t) = 1 + \sum_ {k \in [ - \Delta t, \Delta t ]} f (\operatorname {C o u n t} (x, y, t + k)). \tag {3}
$$

By adjusting these parameters, we can control the trade-off betweenpath conflict avoidance and path length: By setting $\Delta t = 0$ and$\alpha = \infty$ in the computation of $f ( n u m _ { k } )$ , we can obtain the optimalconflict-avoiding path, but this will substantially increase the timerequired to acquire the path. Conversely, by setting $\Delta t = 0$ and$\alpha = 0$ , we can obtain the naive shortest path. When $\Delta t$ is non-zero,PlCC provides an interpolation between the shortest path (whichmay have conflicts) and the optimal conflict-free path, balancingboth path length and conflict avoidance.

4.1.2 Perceived Congestion Cost. However, when utilizing the PlCCalone, agents consider the impact of planned trajectories, but donot account for the potential influence of future unplanned agents.The avoidance of congestion between agents relies entirely on theplanning of the subsequent agents, which places a heavy burden onthe future agents. This can, to a certain extent, affect the congestionavoidance effectiveness between some agents, thereby impactingthe overall efficiency of the multi-agent system. To address this, thePerceived Congestion Cost (PeCC) is proposed.

This PeCC is calculated based on the real-time field-of-view per-ception of each agent, allowing agents to account for their mutualinfluence, rather than just one agent influencing another. The costdesign can relieve congestion during path search.

Furthermore, to ensure the timeliness of the PeCC, we introducea decay factor as follows:

$$
\operatorname {c o s t} _ {P e C C} (x, y, t) = \sum_ {k \in [ - t, 0 ]} \gamma^ {t _ {0} - t} A t C e l l (x, y, t + k). \tag {4}
$$

The indicator function $A t C e l l ( x , y , t )$ returns 1 if an agent wasobserved (by the current agent) at the location $( x , y )$ at timestep$t + k$ , and 0 otherwise. Let $c$ denote the cell at position $( x , y )$ .

Leveraging the preceding results, we can demonstrate that thefollowing recursive relationships are satisfied:

$$
c o s t _ {P e C C} (c, t _ {0} + 1) = \gamma c o s t _ {P e C C} (c, t _ {0}) + A t C e l l (c, t _ {0}). \tag {5}
$$

# 5.3 In-depth Analysis of SMAPO

In this section, we conduct an evaluation of the performance im-pacts associated with various design components of SMAPO. Theassessment proceeds in a hierarchical manner: initially, we evaluatethe overall effectiveness of the Primordial Planning phase and theDecision Refinement phase. Subsequently, we perform a detailedanalysis of each specific design element within these two phases,as well as the Dual Transformation (DT).

Impact of PP phase and DR phase. To evaluate the impact ofthe Primordial Planning (PP) and Decision Refinement (DR) phases,we design two ablations 1) SMAPO-PP, which trains a modelsolely based on the DR phase by removing the PP phase fromSMAPO; and 2) SMAPO-DR, which makes decisions directly usingthe planning results from the PP phase. As shown in Figure 3, boththe absence of PP phase and DR phase significantly degrade theperformance on Pico-Random map. Notably, SMAPO-DR exhibitslonger runtime than SMAPO $\Delta = 6 4 . 7 3 \%$ on average). We attributethis to suboptimal planning in PP phase: 1) The retained conflictsfrom PP phase destabilize the PeCC; 2) Such instability reducesheuristic reliability, impeding search efficiency and prolongingcomputation time. This proves that combining PP and DR phasesensures both superior performance and efficiency.

Planning Algorithm Design in the PP phase. As described inSection 4.1, we developed LB- $\cdot \mathbf { A } ^ { \star }$ to rapidly generate a congestion-aware initial path set during the PP phase. To assess the perfor-mance advantages of LB- $\cdot \mathrm { A } ^ { \star }$ and its individual components, we de-signed three ablation studies: 1) SMAPO-LB, which replaces LB-A*with the classic $\mathsf { A } ^ { \star }$ [11]; 2) SMAPO-Pl, which removes PlCC fromthe cost calculation; and 3) SMAPO-Pe, which excludes PeCC fromthe cost computation. We report the evaluation results on City mapfrom MovingAI in Table 2. The table demonstrates that SMAPO ex-hibits significantly superior performance compared to SMAPO-Pl,

SMAPO-Pe, and SMAPO-LB. Notably, SMAPO-LB shows the weak-est performance in all tested scenarios. These findings reveal twokey observations: 1) Both PlCC and PeCC substantially influencethe performance of LB- $\mathbf { A } ^ { \star }$ ; 2) Although removing PlCC or PeCCdegrades the quality of LB-A*’s path sets, they still outperformclassical $\mathbb { A } ^ { \star }$ algorithms. This performance disparity stems from theimplicit collaboration embedded in PlCC and PeCC designs, whichfacilitates multi-agent coordination in LMAPF systems to securebalanced traffic load.

Network Architecture Design in the DR phase. As detailed inSection 4.2, we proposed a neural network to optimize the initialpath configurations during the DR phase. Here, we investigate onwhat extent these designs influence SMAPO’s learning effectiveness.Concretely, for the Interaction Perception module (IP), we introduceone ablation SMAPO-IP: cancel the information sharing betweenthe nearby agents by replacing the IP module by an MLP layer. # 6 Conclusion

In this paper, we propose SMAPO, a search-integrated learningframework for rapid generation and optimization of load-balancedpath sets. SMAPO comprises two tightly-coupled phases: 1) Pri-mordial Planning phase employing a novel load-balancing $\mathbb { A } ^ { \star }$ algo-rithm that integrates planning and perceived congestion costs toenhance solution quality through spatiotemporal load distributionand conflict mitigation; 2) Decision Refinement phase formulatecollaborative path set optimization as the primary objective andemploy multi-agent reinforcement learning to develop an Encoder-Decoder-based cooperative policy. Additionally, we utilize dualtransformations to augment trajectory samples during online learn-ing, boosting sample utilization and overall learning stability. Ex-tensive evaluations on LMAPF benchmarks demonstrate SMAPO’sconsistent superiority over state-of-the-art learning methods and itssuperior performance-efficiency balance compared to search-basedapproaches. Future work involves enriching agent action diversityand extending SMAPO to dynamic obstacle environments.
