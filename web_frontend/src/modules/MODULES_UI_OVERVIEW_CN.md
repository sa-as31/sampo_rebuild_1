# Modules 界面说明（中文）

本文档用于说明 `web_frontend/src/modules/` 下各个 `.vue` 文件所对应的页面界面、主要职责和典型展示内容，便于答辩汇报、代码讲解和现场修改代码时快速定位。

## 1. `taskcenter/TaskCenterView.vue`

**对应界面：**
- 任务中心

**主要面向对象：**
- 管理员
- 执行者

**界面作用：**
- 这是系统最核心的业务页面，负责围绕“任务”组织整个工作流。
- 管理员在这里创建任务、分配执行者、导入地图、查看执行中任务和已完成任务。
- 执行者在这里查看自己的任务列表、进入任务详情、处理反馈和查看回放。

**页面特点：**
- 支持管理员 / 执行者双视图；
- 支持任务筛选、日期过滤、任务详情展开与收起；
- 支持历史回放、告警、反馈等任务上下文能力。

**答辩时容易修改的点：**
- 默认是否展开任务详情；
- 某个筛选条件或排序规则；
- 表格列、状态文案、按钮显示逻辑；
- 某个任务区块的默认提示文字。

## 2. `dashboard/OpsDashboardView.vue`

**对应界面：**
- 运营大屏

**主要面向对象：**
- 执行者
- 管理员（演示与监控时也可使用）

**界面作用：**
- 用于展示系统整体运行情况和当前重点任务状态。
- 页面会展示任务总数、运行中任务、已完成任务、平均吞吐量等指标。
- 同时支持聚焦某个任务，查看实时地图快照和最近告警。

**页面特点：**
- 偏监控视角；
- 强调“全局态势 + 焦点任务”；
- 自动刷新任务列表和快照。

**答辩时容易修改的点：**
- 增减一个指标卡；
- 修改自动刷新频率；
- 调整默认聚焦哪个任务；
- 更改表格展示字段。

## 3. `operations/OperationsModeView.vue`

**对应界面：**
- 2D + 3D 联合运行视图

**主要面向对象：**
- 管理员
- 执行者

**界面作用：**
- 这是最适合演示系统动态效果的页面。
- 页面把 2D 俯视运行状态和 3D 运行状态放在同一个任务上下文里。
- 支持任务启动、暂停、继续、停止，也支持选中无人机查看状态。

**页面特点：**
- 2D 与 3D 使用同一任务、同一帧数据；
- 支持模板切换、任务参数、镜头模式、放大倍率、环绕速度等配置；
- 支持实时告警和无人机状态表。

**答辩时容易修改的点：**
- 默认镜头模式；
- 回放速度、缩放倍率、默认模板；
- 2D/3D 某个提示文案；
- 表格中增加一列显示信息。

## 4. `research/ResearchModeView.vue`

**对应界面：**
- 研究 / 推理配置页

**主要面向对象：**
- 管理员
- 算法调试人员

**界面作用：**
- 用于手动填写推理参数，调用后端推理接口，并回放结果。
- 更偏“实验与调试”用途，而不是任务执行用途。

**页面特点：**
- 支持填写 `cfg_dir`、`checkpoint_path`、`device`、`map_name` 等参数；
- 支持加载前端样例数据；
- 支持通过滑块播放回放帧和查看指标日志。

**答辩时容易修改的点：**
- 默认推理参数；
- 预设按钮内容；
- 播放速度或状态文案；
- 指标显示项。

## 5. `simulation3d/Simulation3DView.vue`

**对应界面：**
- 独立 3D 仿真预览页

**主要面向对象：**
- 演示汇报
- 可视化展示

**界面作用：**
- 负责将 2D 地图与回放数据映射到 3D 视图中。
- 支持从前端示例数据或后端真实推理数据加载回放。
- 主要用于展示系统的三维动态效果。

**页面特点：**
- 支持环绕观察、全局俯视、跟随视角、无人机视角；
- 支持视图放大、回放速度调节、无人机切换；
- 支持鼠标拖拽调整视角。

**答辩时容易修改的点：**
- 默认相机模式；
- 默认放大倍率和环绕速度；
- 某个视角下的提示文字；
- 指标卡内容或显示顺序。

## 6. 这几个页面之间的关系

可以把这些页面理解为三类：

- **任务驱动页**
  - `TaskCenterView.vue`
  - 负责围绕“任务”组织业务流程。

- **监控展示页**
  - `OpsDashboardView.vue`
  - `OperationsModeView.vue`
  - 用于观察任务整体情况与运行细节。

- **实验与演示页**
  - `ResearchModeView.vue`
  - `Simulation3DView.vue`
  - 用于推理调试、三维展示和答辩演示。

## 7. 答辩前最建议熟悉的页面

如果答辩前时间有限，优先熟悉以下三个页面：

1. `taskcenter/TaskCenterView.vue`
2. `dashboard/OpsDashboardView.vue`
3. `operations/OperationsModeView.vue`

原因是：

- 它们最贴近“真实系统界面”；
- 改动后最容易马上看到效果；
- 老师最可能围绕这些页面让你现场做小改动。
